Features

Long captures, handled simply.

Everything you need to turn a long page or document into a single image, and nothing you do not.

Global hotkey, menu bar only

Lives in the menu bar with no Dock icon. Start a capture with the default ⇧⌘8 shortcut, or record your own in Settings.

Automatic or manual scrolling

Automatic mode scrolls the region for you and stops when the bottom is reached, you press Esc, or it hits 40 frames. Manual mode grabs a frame every 300 ms while you scroll by hand.

Overlap-based stitching

Frames are aligned by comparing rows of downsampled grayscale pixels, and only the new rows are appended. If a match is poor, the result is flagged as possibly misaligned.

Trim sticky headers and footers

Crop a set number of points from the top and bottom of every frame after the first, so fixed bars appear only once. Scroll step and delay are adjustable too.

Retina and multi-display aware

Capture size and scroll offsets account for the display's scale factor, and the region is captured from the display you drew it on.

PNG to folder or clipboard

Save to a folder you choose, optionally copy to the clipboard, and optionally play a sound. Images taller than 16,000 px are split into numbered files.

Install

Up and running in a minute.

ScrollStitchShot is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download ScrollStitchShot-macOS.zip and unzip it.
  2. Move ScrollStitchShot.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/ScrollStitchShot.app
  4. When prompted, grant Screen Recording in System Settings Privacy Security, and Accessibility there too if you want automatic scrolling (manual mode works without it).

FAQ

Questions, answered.

Is ScrollStitchShot really free and open source?

Yes. It is released under the MIT license, the full source is on GitHub, and there are no paid tiers. It uses only Apple frameworks, with no third-party dependencies.

What permissions does it need?

Screen Recording is required to capture the region you select. Accessibility is needed only for automatic mode, to send scroll-wheel events. The app does not request microphone, camera, or network access.

Where is my data stored?

Captures are saved as PNG files in the folder you choose in Settings, falling back to the Desktop if that folder is missing. Preferences are stored locally on your Mac, and the app makes no network calls and has no analytics.

Why is the app not notarized?

Notarization requires a paid Apple Developer account, and this is a free open-source project. Right-click the app and choose Open once to get past Gatekeeper, or build it from source with Xcode.

Was this written by AI?

Yes.
